generation on 2026-10-08 for the marketing page. Its caption explicitly excludes
it from field evidence. It must never be seeded as a report or a model evaluation.

`leaflet@1.9.4` npm package. Its BSD license is in `LICENSE`. Map tiles are loaded
from OpenStreetMap only after the user chooses Show map, with visible attribution.
